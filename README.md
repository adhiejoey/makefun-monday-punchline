Entry for the make.fun bounty **Monday Morning Punchlines** (slug `u-gentle-badger-68-monday-morning-punchlines-709645dc`, $5 prize).

`main.ts` writes a single original Monday-morning joke — one line, plain ASCII, under 200 characters — to `entry.txt` in the directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`).

The joke: the weekend didn't really end on Monday morning; it just dressed up for work and started charging rent — a fresh twist that avoids the usual coffee and alarm-clock cliches.

Run it with:

```sh
node main.ts
```
